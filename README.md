# 🚀 Mir Musaib — Portfolio

A modern, responsive personal portfolio built with **React + Vite**, designed for an **AI / ML Engineer** profile.  
It showcases my skills, projects, education, and contact details with a clean, minimal, AI-themed design.

🔗 **Live Website:**  
👉 https://meermusaib20.github.io/Portfolio

---

## ✨ Features

- 🎨 Modern AI-themed abstract background
- 🧠 Clean hero section with floating profile image
- 🧩 6-call-to-action grid (Projects, Skills, About, Education, Contact, Resume)
- 📄 Resume download (PDF)
- 🧭 Fixed navbar with active section highlighting
- 📱 Fully responsive (desktop & mobile)
- ⚡ Fast build with Vite
- 🌍 Deployed using GitHub Pages

---

## 🛠️ Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** CSS (custom, no frameworks)
- **Deployment:** GitHub Pages
- **Version Control:** Git & GitHub

## 🚀 Getting Started (Local Setup)

Clone the repository:

```bash
git clone https://github.com/meermusaib20/portfolio.git
cd portfolio/ai_portfolio
```
Install dependencies:
```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

##🌍 Deployment

This project is deployed using GitHub Pages.

```bash
npm run deploy
```
Make sure:
	•	vite.config.js has base: "/portfolio/"
	•	package.json includes deploy scripts and homepage URL
